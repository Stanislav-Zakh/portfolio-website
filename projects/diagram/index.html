LampLight: A Powerful and Customizable Tool

LampLight is a diagram-building tool that leverages three core technologies: Angular, D3.js, and SVG. D3.js plays a crucial role in data binding, element lifecycle management, and simulating force behavior, enabling smooth interactions within the tool. SVG, combined with CSS, handles most of the graphical elements, including the board and node selection menu, ensuring a visually rich and responsive interface.

Node Selection and Diagram Building

Users begin by selecting a node from the Node Selection Menu and placing it on the board—the main workspace where diagrams take shape. LampLight currently supports three primary elements: Nodes, Links, and Text. While this may seem minimal, each element is highly customizable, allowing users to create clear and visually distinct diagrams.

The Building Blocks of LampLight

Nodes offer extensive customization options, including shape, size, rotation, and color adjustments. This flexibility ensures that each node stands out and serves its intended purpose. Links, on the other hand, connect nodes and always render beneath other elements. Users can create links by selecting two or more nodes and connecting them via the context menu. These links can be further customized with directional arrows, varying shapes, colors, and two distinct types—curved or straight.

Adding Context with Customizable Text

Text nodes provide essential context to diagrams and are treated like any other node, with one key difference: they have the highest rendering priority, ensuring that text remains clearly visible above other elements. Users can personalize text by adjusting font size, color, and style, enhancing readability and aesthetic appeal. By combining these customizable elements, LampLight empowers users to design intricate, well-structured diagrams with ease. As development continues, additional features will further expand the tool’s capabilities, making it even more versatile for users who need precise and visually compelling diagrams.
